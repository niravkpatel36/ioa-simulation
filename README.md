# Island of Adventures

Just the video. Open the page, wait for it to load, and use the keyboard:

| Key | What it does |
|-----|--------------|
| **Space** | ROW (kids are rowing) |
| **W** | WAIT (boat is still, loops) |
| **A** | ARRIVE (plays once, then holds the final island picture) |
| **0** | Start over (back to WAIT) |
| F | Fullscreen on/off |
| M | Sound mute/unmute |

It always starts on WAIT and loops until you press something.
Press any key or click once after loading so the browser allows sound.

After ARRIVE, only **0** works (to start over).

Tips: open it 10+ minutes early so the videos finish loading, plug the Mac in, don't refresh during the show.

To change videos: replace the files in `videos/` (keep the names wait.mp4, row.mp4, arrive.mp4) and upload to GitHub; Vercel redeploys automatically.
